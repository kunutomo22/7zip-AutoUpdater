# 7zip-AutoUpdater
7zipをサイレントアップデートするツールです。
## 使い方
1. Releaseの最新版を取得する。  
2. zipを展開する。
3. `7zip-AutoUpdate.ps1`を**管理者権限**で実行する。  
  
この手順でリリース履歴一覧をCSV形式で取得できます。
### 必要最低限のもの
- Powershell 5.1以上
- このプロジェクトにある以下のファイルとフォルダ
    - `7zip-AutoUpdate.ps1`
    - `Common`
    - `Subshell`
    - `Setting.txt`
### ツールの設定について
`Setting.txt`を編集することで、インストーラを残すかどうかやインストール先などを変更できます。  
詳細は`Setting.txt`の中にあるコメントを参照してください。
## ツールの仕様
実行時の最新バージョンになるように7zipをアップデートorインストールします。
